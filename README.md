# DXVK-Sarek-FMOD

**Vulkan 1.3 based implementation of D3D3, 5, 6, 7, 8, 9, 10 and 11 for Linux/Wine/Proton.**


A special version of DXVK Sarek optimized exclusively for Vulkan 1.3, designed for devices with problematic drivers—such as those on Android.
